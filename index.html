PsySH

A runtime developer console, interactive debugger and REPL for PHP.

Install

Download directly:

wget https://psysh.org/psysh
chmod +x psysh
./psysh

Or install via Composer:

composer require psy/psysh

Or install globally:

composer global require psy/psysh

Features

  • A powerful interactive REPL (Read-Eval-Print Loop)
  • Built-in doc command for inline PHP documentation
  • The show command to view source code for any function, class, or method
  • Tab completion for classes, functions, variables, and more
  • An interactive debugger; drop eval(\Psy\sh()) anywhere in your code
  • Reflection and introspection with ls; explore any class, object, or namespace
  • Exception handling; forgot to catch one? Use wtf to see it
  • Proper namespace support; most PHP shells are terrible at this
  • Show, search, save, and replay your shell history
  • Laravel Tinker, Drush, WP-CLI, and other framework integrations
